Title: CSV & Excel Data Cleaning Workspace

Role: Developer — personal portfolio demo, built with AI assistance

Description:
Clearframe is a browser-based tool for inspecting and cleaning CSV and Excel data. Users can identify missing values and duplicate rows, choose cleaning rules, and compare the result with the original. The app exports cleaned CSV/XLSX files and a detailed change report. Files are processed locally in the browser. Built as a personal demo with AI assistance, with automated tests for the core cleaning logic.

Skills: JavaScript, Data Processing, Web Development, Data Cleaning, Software Testing
